# EXP-002：监督微调基线

## 状态

**代码实现：完成。**  
**32 样本 LoRA 冒烟：通过。**  
**374 样本正式 SFT：完成。**  
**90 题 validation 前后对照：完成。**

## 研究目的

建立与基础模型完全可比的监督微调基线，为后续组相对策略优化（GRPO）提供参照。

核心问题：

1. SFT 对 Pass@1 / Pass@4 的影响；
2. 单次命中率和多次采样覆盖率是否同步提升；
3. 代码语法/格式能力是否改善；
4. 公共测试与隐藏测试之间是否出现差距；
5. 后续 GRPO 在同一数据和评测下还能带来什么。

## TRL 1.14.1 接口修复

固定版本的 `SFTConfig` 不提供 `warmup_ratio`，只提供 `warmup_steps`。

项目仍在 YAML 中保留 5% 预热比例作为实验语义，然后根据样本数、epoch、batch size 和梯度累积确定性转换为优化器步数：

- 32 样本 / 1 epoch：1 个预热步；
- 374 样本 / 3 epoch：4 个预热步。

## 正式 validation 评测

评测代码包含批量采样优化，GitHub 提交：

`021d08a5a16250c349a179cec72a823f6d659437`

批量采样先在 2 题 × 4 候选上做了双次复现：

```text
IDENTICAL=1
```

即同模型、同参数、同种子生成文件逐字节一致。

正式验证：

- 90 道 MBPP validation；
- 每题 4 个候选；
- 共 360 个候选/模型；
- 基础模型与 SFT 使用相同任务、提示、温度、top-p、最大长度和随机种子；
- 全部通过同一 Docker 执行器和隐藏测试。

### 核心结果

| 指标 | 基础模型 | SFT | 变化 |
|---|---:|---:|---:|
| Pass@1 | 13.61% | 25.56% | **+11.94 个百分点** |
| Pass@4 | 38.89% | 43.33% | **+4.44 个百分点** |
| 语法失败 | 182 / 360 | 0 / 360 | **-182** |
| 平均公共测试通过率 | 14.17% | 27.78% | +13.61 个百分点 |
| 平均隐藏测试通过率 | 14.86% | 28.19% | +13.33 个百分点 |
| 隐藏测试全通过候选 | 49 / 360 | 92 / 360 | +43 |
| 至少有一个正确候选的题 | 35 / 90 | 39 / 90 | +4 |
| 4/4 候选全正确的题 | 0 / 90 | 8 / 90 | +8 |

### 公共/隐藏测试差距

基础模型：

- 公共测试全通过候选：51
- 公共全通过但隐藏失败：5

SFT：

- 公共测试全通过候选：100
- 公共全通过但隐藏失败：14

SFT 极大提升了“能写出语法正确、看起来能工作的代码”的概率，但仍有一部分候选只通过稀疏公共测试，无法通过隐藏测试。

这不是“验证测试过拟合”的直接证据，因为 SFT 阶段没有使用 validation 公共测试训练；它说明 **少量测试不足以准确代表真实功能正确性**，进一步支持后续使用更强隐藏测试 / MBPP+。

### 按题变化

90 道验证题中：

- 30 题：SFT 正确候选数增加；
- 10 题：SFT 正确候选数减少；
- 50 题：不变；
- 13 题：基础模型 4 次全错，SFT 至少解出 1 次；
- 9 题：基础模型至少解出 1 次，SFT 4 次全错。

因此 SFT 不是单调改善每一道题，而是在改变整个输出分布。

## 关键观察

### 1. SFT 明显改善单次可用性

Pass@1 从 13.61% 到 25.56%，接近翻倍。

### 2. Pass@4 增益远小于 Pass@1

Pass@4 只从 38.89% 到 43.33%。

这提示：

> SFT 的主要收益至少有一部分来自把原本低概率的正确代码提升为更高概率输出，而不是等比例扩大可探索到的正确解集合。

这只是行为层面的初步信号，真正“能力边界”判断需要更大的 k 和独立外部基准。

### 3. 语法能力改善非常显著

基础模型 360 个候选中有 182 个语法失败；SFT 后为 0。

说明仅 374 条高质量代码监督，就足以显著改善 0.6B Base 模型的代码输出格式与可执行性。

### 4. 功能正确性仍远未解决

SFT 后 Pass@1 仍只有 25.56%，而且仍存在公共测试通过、隐藏测试失败候选。

所以后续可验证奖励强化学习（RLVR）有明确优化空间。

## EXP-002 结论边界

当前可以说：

- 在固定 MBPP-v1、固定 Qwen3-0.6B-Base 和统一评测下，LoRA SFT 显著提升单次代码正确率与语法有效性；
- SFT 对 Pass@1 的提升明显大于 Pass@4；
- SFT 并非对所有题单调改善；
- 更强隐藏测试仍然必要。

当前不能说：

- SFT 或 RL 创造了基础模型原本不存在的新能力；
- 这些结果可以代表无污染泛化；
- 0.6B 结果可以直接外推到 1.7B/4B。

这些需要后续更大 k、MBPP+、LiveCodeBench 和更大模型对照。
