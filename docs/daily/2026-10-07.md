## EXP-004C 追加记录：No-op 因果控制

### 问题：No-op DPO 理论无偏好梯度，但 adapter 仍有微小漂移

普通 No-op：chosen == rejected，训练 loss 恒约 0.6931，reward margin 为 0。

但训练后 adapter 相对 SFT：

- changed tensors：392 / 392；
- changed values：约 99.52%；
- relative L2：约 1.87e-4；
- max abs delta：约 4.84e-6。

### 假设 1：LoRA dropout 导致 chosen / rejected 前向不一致

操作：新增 No-op dropout=0 控制。

结果：关闭 dropout 后仍出现同量级漂移：

- changed tensors：392 / 392；
- changed values：约 99.52%；
- relative L2：约 1.80e-4；
- max abs delta：约 4.86e-6。

结论：LoRA dropout 不是充分解释。

### 假设 2：保存/加载或训练流水线本身会改权重

操作：新增 zero-learning-rate No-op 控制：

- chosen == rejected；
- adapter dropout = 0；
- learning rate = 0；
- 其余 DPO 流水线保持不变。

结果：

- SFT SHA-256：e1ea9a007a3e4213cdeb1ca6b1e12d29adb83594991421757d0d40b9168d0861；
- zero-lr 输出 SHA-256：完全相同；
- changed tensors：0 / 392；
- changed values：0；
- relative L2：0；
- max abs delta：0；
- exact tensor equality：true。

结论：

> 保存/加载和训练流水线本身不会修改 adapter。No-op 在非零学习率下出现的漂移来自实际的极小参数更新，而不是 serialization artifact。

### 行为级初步结果：普通 No-op(dropout=0.05)

固定 90 题 ×16、同 seed，与原 SFT 逐样本比较：

- rows compared：1440；
- exact completion matches：1001；
- exact match fraction：69.51%；
- changed rows：439；
- changed tasks：85 / 90。

因此约 1e-4 相对 L2 的微小权重漂移已经足以明显改变采样输出。

### 工程问题：GPU 控制实验意外并发

发现 No-op dropout=0 行为评测和 zero-lr DPO 控制同时占用 GPU。

风险：虽然固定 seed，但并发 GPU 负载可能成为额外可重复性混杂因素。

处理：

1. 识别两个进程及父脚本；
2. 保留更关键的 zero-lr 控制独占 GPU；
3. 中止 No-op dropout=0 行为评测；
4. 发现父脚本终止后生成子进程成为孤儿，随后显式 kill；
5. zero-lr 完成后，从干净状态串行重跑 dropout=0 行为评测。

这次并发产生的部分 dropout=0 predictions 不作为正式结果。

## EXP-004D：Matched-Norm 随机参数扰动控制启动

### 研究动机

EXP-004C 已排除：

- 固定 seed 生成链路自身非确定性；
- 保存/加载导致权重变化；
- 正确 preference direction 是高 k 覆盖恢复必要条件；
- exact-output entropy 必须上升。

剩余替代解释：

> 是否任意同量级局部参数扰动都能产生类似高 k 覆盖恢复？

### 控制设计

从 1.7B SFT adapter 出发，以 No-op dropout=0.05 adapter - SFT adapter 为幅度参照。

对每个 LoRA tensor：

1. 读取 No-op05 对应 tensor 的 delta L2；
2. 采样高斯随机方向；
3. 归一化后乘以相同 tensor delta L2；
4. 加回 SFT tensor；
5. 不经过 DPO、optimizer、preference pair 或 reward。

正式随机 seeds：101 / 202 / 303。

### 工程实现

新增：

- src/coderl_lab/analysis/matched_norm_perturb.py
- tests/test_matched_norm_perturb.py
- scripts/run_exp004d_generate.sh
- scripts/run_exp004d_eval.sh
- experiments/EXP-004D-matched-norm-perturbation.md

PR：#19。

### 单元测试

111 / 111 passed。

### 几何约束验证

No-op05 global delta L2：约 0.0062008071。

三个随机 perturbation：

- seed101 delta L2 ≈ 0.0062008123；
- seed202 ≈ 0.0062008120；
- seed303 ≈ 0.0062008118。

global norm ratio 均约 1.0000007。

与 No-op05 delta 的 cosine：

- seed101：-0.0001197；
- seed202：-0.0000250；
- seed303：-0.0001692。

三个随机 seed 彼此 cosine 也都约 1e-4 量级，接近正交。

因此：

> matched-norm 构造达到了“幅度匹配、方向随机”的预注册要求。

### 机制结论

三个近乎正交的随机方向，在完全不经过 DPO 的情况下，都出现：

- Pass@8 / Pass@16 提升；
- solved@16 增加；
- success HHI 下降；
- effective task count 上升；
- 约 29%–31% 固定 seed completion 改变。

因此当前最符合证据的解释是：

## EXP-004E：扰动幅度剂量—响应启动

### 研究问题

EXP-004D 已证明：不经过 DPO、只对 SFT adapter 施加与 No-op05 同量级的随机方向局部扰动，3/3 个随机 seed 都能提高高 k 覆盖。

### 预注册设计

scale：

- 0×：原 SFT；
- 0.25×；
- 0.5×；
- 1×：复用 EXP-004D；
- 2×。

随机方向固定：101 / 202 / 303。

同一个 seed 在不同 scale 下必须保持相同方向，只改变 per-tensor norm。

### 工程实现

在 matched_norm_perturb 中新增 scale 参数。

新增测试：

- scale 改变范数但不改变随机方向；

- 2× ≈ 0.012401628；

- 同 seed 跨 scale cosine 均 > 0.9999997。

因此正式控制达到了“方向固定、只改变幅度”的因果要求。

## EXP-004E 追加记录：局部参数扰动剂量—响应

### 正式设计

固定 EXP-004D 的三个随机方向 seed=101/202/303，只改变每 tensor 扰动范数：

- 0×：原始 SFT；
- 0.25×；
- 0.5×；
- 1×：复用 EXP-004D；
- 2×。

0.25× / 0.5× / 2× 共 9 个新 arm 均完成 90题×16 的正式评测。

### 三 seed 平均结果

- 0.25×：Pass@16 +3.33 pp，solved@16 +3.0；
- 0.5×：Pass@16 +5.19 pp，solved@16 +4.67；
- 1×：Pass@16 +3.70 pp，solved@16 +3.33；
- 2×：Pass@16 +4.81 pp，solved@16 +4.33。

0.5× 当前点估计最强，但不是单调剂量关系。

### 同随机方向跨尺度配对

0.25×→0.5×：
- Pass@8 +1.44 pp，95% CI [-0.05,+2.99]；
- Pass@16 +1.85 pp，95% CI [-0.74,+4.44]。

0.5×→1×：
- Pass@8 -1.56 pp，95% CI [-2.87,-0.47]；
- Pass@16 -1.48 pp，95% CI [-3.70,+0.37]。

1×→2×：
- Pass@8 +1.21 pp，95% CI [+0.13,+2.44]；
- Pass@16 +1.11 pp，95% CI [-0.74,+3.33]。

0.5× vs 2×：
- Pass@8 / Pass@16 均无显著差异。

### 行为漂移

fixed-seed exact completion match：

- 0.25× ≈ 68.54%；
- 0.5× ≈ 69.07%；
- 1× ≈ 69.84%；
- 2× ≈ 69.63%。

从 0.25× 起行为漂移已经接近饱和，没有随扰动尺度单调增大。

### 机制结论

当前更支持：

> SFT adapter 位于一个对随机采样高度敏感的局部区域。很小扰动就足以改变 token 采样边界并造成 autoregressive trajectory 分叉；继续增加参数距离不会线性增加行为变化或覆盖收益。

因此不能把 EXP-004D/E 简单解释成“参数越不稳定越好”。
