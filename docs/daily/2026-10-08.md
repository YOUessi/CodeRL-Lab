### 当前解释

当前正式证据已经否定“只有随机采样才会放大 tiny parameter perturbation”。

更符合数据的是：

tiny parameter perturbation
→ prompt 起点分布只有很小变化，top-1 仍不变
→ 后续 autoregressive prefix 改变局部分布
→ 某个低 margin 决策点发生 argmax 翻转
→ 后续 deterministic greedy trajectory 级联分叉
→ stochastic sampling 在此基础上再叠加额外分叉。

因此更准确的研究问题已经从“sampling amplification”扩展为：

> deterministic autoregressive amplification + additional stochastic amplification。

## EXP-004G：Trajectory Susceptibility / 低 Margin 决策边界

### 启动原因

EXP-004F 已经确认：

- prompt 起点 top1 在 12/12 matched perturbation arm 中保持 100% 一致；
- prompt-end KL / TV 很小；
- 但 deterministic greedy 仍有约 20%–34% task 分叉；
- 首次分叉多数发生在 low-margin / tie token；
- stochastic sampling 只是额外放大器。

因此下一问题从“为什么会分叉”推进到：

> 能不能只看 SFT 自己的 greedy margin profile，就提前预测哪些 task 对 tiny parameter perturbation 更脆弱？

### 预注册主要检验

主要 outcome：

- 12 个 matched perturbation greedy arm 中的 task divergence rate。

主要 predictor：

- SFT greedy 前 min(128, completion length) token 中 probability top1-top2 margin ≤ 0.05 的比例。

主要统计：

- Spearman correlation；
- 20,000 次 task bootstrap；
- seed=42；
- 95% CI 完全 >0 才认为主要假设得到支持。

长度控制：

- divergence_rate ~ standardized(low-margin fraction) + standardized(log1p(token count))；
- 对 low-margin coefficient 做 20,000 次 bootstrap。

次要指标：

- margin≤0.01 / ≤0.10；
- tie fraction；
- p10 / median / min margin；
- predictor top quartile vs bottom quartile；
- 各 perturbation scale 分别的相关。

### 工程策略

- 不训练新模型；
- susceptibility labels 完全复用 EXP-004F 12 个 greedy arm；
- GPU 只重新计算一次 SFT 90-task greedy trajectory margin profile；
- 后续全部 CPU 统计；
- hidden correctness 不参与 susceptibility label，避免任务结果泄漏进主要机制分析。
